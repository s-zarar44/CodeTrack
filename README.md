# CodeTrack

CodeTrack is a full-stack competitive programming analytics platform that brings a user's coding activity and performance statistics into a unified dashboard.

## Planned Features

- User authentication and profiles
- Competitive programming platform integration
- Problem-solving statistics
- Contest and rating analytics
- Difficulty distribution
- Activity and progress tracking
- Interactive performance dashboard

## Tech Stack

- Frontend: React, Vite
- Backend: Node.js, Express.js
- Database: PostgreSQL
- ORM: Prisma
- Authentication: JWT
- Version Control: Git, GitHub

## Project Status

🚧 Currently under active development.

The initial version is being developed as a full-stack application with a focus on clean architecture, REST APIs, relational database design, analytics, and a responsive user interface.
